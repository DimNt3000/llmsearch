# BM25: the workhorse ranking function

BM25 (Best Matching 25) is a probabilistic ranking function that scores how
relevant a document is to a query. It is the default ranker in Lucene,
Elasticsearch, and OpenSearch, and remains a very strong baseline that neural
retrieval models are still measured against.

BM25 improves on plain TF-IDF with two ideas.

First, term-frequency saturation. In TF-IDF, a document that mentions a query
term twenty times scores twice as high as one that mentions it ten times. BM25
instead lets the contribution of repeated terms level off: the k1 parameter
(typically around 1.2 to 2.0) controls how quickly additional occurrences stop
adding score. The intuition is that after a handful of mentions, a document is
already clearly "about" that term.

Second, document length normalization. Long documents naturally contain more
term occurrences, so BM25 divides the term frequency by a factor based on the
document's length relative to the average document length in the collection.
The b parameter (typically 0.75) controls how strong this normalization is:
b = 1 fully normalizes by length, b = 0 ignores length entirely.

Each query term also carries an inverse document frequency (IDF) weight: terms
that appear in few documents are more informative than terms that appear
everywhere, so rare terms contribute more to the score. Stopwords like "the"
carry almost no weight, which is why many engines simply drop them.

The full score of a document D for query Q is the sum over query terms of
IDF(t) multiplied by a saturated, length-normalized term frequency. Despite its
age — it comes from the Okapi information retrieval system of the 1990s — BM25
is hard to beat when queries and documents share vocabulary, which is why
hybrid systems combine BM25 with embedding-based semantic search instead of
replacing it.
